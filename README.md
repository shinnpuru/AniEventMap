# AniEventMap

按地区、作品和日期查找二次元展览、快闪、演出和同人Only。当前从上海开始，持续扩展其他地区。

**[打开活动地图](https://shinnpuru.github.io/AniEventMap/)**

## 使用

- 点击地图标记查看活动；同址有多场活动时，点击场馆标记展开列表。
- 点击左上角菜单展开侧栏，按地区、作品、日期、类别筛选，或搜索活动及地点。
- 点击「地图定位」找到场馆；详情中可跳转高德导航，以及票务页面购票或预约。
- 点击爱心加入「想去」。收藏保存在当前浏览器，不跨设备同步。
- 点击详情中的分享按钮复制活动链接。

地区列表只显示已收录活动的城市。活动信息并非实时票务库存，最新场次和余票请查看来源页面。
