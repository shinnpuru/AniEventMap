# 活动字段填写指南

Agent 投稿只修改 `src/data/events.json`，无需安装环境。先阅读本指南再填写；实际结构以 [src/data.ts](../src/data.ts) 为准。下列必填是指 JSON 中必须有该字段；可选字段没有可靠信息就省略，不填 null。日期统一使用 YYYY-MM-DD，数字和布尔值不加引号。

## 活动类别怎么选

每个活动只能填一个 type，以活动主要内容和参与方式判断，不以名称里是否包含“展”、举办天数、收费与否决定。

| type 值  | 判断标准                                                                     | 例子                                            | 容易混淆的情况                                                |
| -------- | ---------------------------------------------------------------------------- | ----------------------------------------------- | ------------------------------------------------------------- |
| 展览     | 主要体验是参观展陈、原画、设定资料、主题空间或互动装置                       | 魔法少女小圆15周年纪念特展、EVA30周年纪念活动   | 有周边售卖仍可属于展览，前提是参观本身是主要内容              |
| 快闪     | 限时经营或联动体验，以主题商店、周边售卖、餐饮、打卡为主                     | BanG Dream! × 小豆泥联动快闪、少女前线2主题餐厅 | 展示柜或布景不使快闪店变成展览；限时主题咖啡也归快闪          |
| 演出     | 观众按场次观看舞台表演，如音乐会、Live、舞台剧、朗读剧或放映配现场演奏       | 《传说之下》交响音乐会                          | 展会里附带的舞台互动不单独改变整个展会的类别                  |
| 同人Only | 围绕特定作品、系列、角色或 CP 的同人交流或创作贩售活动，通常有同人摊位或社团 | 蔚蓝档案同人ONLY——勇者之路                      | 官方单作品展不是同人Only；综合漫展也不因有同人摊位就成为 Only |

混合活动先看独立售票或预约的对象：同人Only附带声优互动仍归同人Only，音乐会附带周边摊仍归演出。两个可独立参加、独立售票且内容不同的活动可以分别录入；同一活动的票档、日期场次不要拆成重复活动。

无法判断时核实主办方介绍，在 PR 中说明疑点；现有类别确实无法覆盖时提出功能建议，不自行创造新的 type 值或修改代码。

## 顶层字段

| 字段      | 类型 / 必填   | 怎么填                                            |
| --------- | ------------- | ------------------------------------------------- |
| updatedAt | 字符串 / 是   | 本次实际更新日期，例如 2026-09-27，不沿用示例日期 |
| works     | 对象数组 / 是 | 作品目录；复用已有条目，只补本次活动需要的新作品  |
| events    | 对象数组 / 是 | 活动列表；保留无关条目，只新增或修改本次指定活动  |

## works 中每个作品

| 字段         | 类型 / 必填 | 怎么填与例子                                                                                                                                                                            |
| ------------ | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| id           | 字符串 / 是 | 唯一稳定的英文标识，如 blue-archive；活动 workIds 引用它，不能随意改名                                                                                                                  |
| name         | 字符串 / 是 | 作品常用中文名，如蔚蓝档案；无官方或可靠中文名时用原名                                                                                                                                  |
| originalName | 字符串 / 是 | Bangumi 对应条目的原名，如ブルーアーカイブ -Blue Archive-；原作中文作品可与 name 相同                                                                                                   |
| bangumiId    | 正整数 / 是 | Bangumi subject 链接末尾的数字，例如 https://bgm.tv/subject/300648 对应 300648；必须核对条目，不能猜测                                                                                  |
| cover        | URL / 否    | Bangumi 对应条目的封面地址，用于作品列表缩略图；从 `https://api.bgm.tv/v0/subjects/{bangumiId}` 的 `images.small` 获取 HTTPS 地址，不使用活动海报代替；无法获取时省略，页面显示默认图标 |
| color        | 字符串 / 是 | 合法的十六进制颜色，如 #4dace0，可选与作品视觉相近的颜色；不是需要从票务提取的事实                                                                                                      |

游戏活动关联游戏本体，不误用动画或原声。联动可关联多个已核实作品；没有 Bangumi 条目的 IP 保留在标题，不伪造 ID。完全没有可确认的作品关联时先补齐信息，不强行填入无关作品。

## events 中每个活动

### 名称与地点

| 字段               | 类型 / 必填     | 怎么填与例子                                                                                                                |
| ------------------ | --------------- | --------------------------------------------------------------------------------------------------------------------------- |
| id                 | 字符串 / 是     | 稳定唯一，例如 bilibili-1005201、damai-1072650157253；已存在活动换票务来源仍保留原 ID。无平台 ID 时使用不冲突的稳定英文标识 |
| title              | 字符串 / 是     | 来源中的活动名称，保留必要站次或主题；可去掉重复的城市前缀，不添加“火爆”“必去”等营销词                                      |
| workIds            | 字符串数组 / 是 | 至少一个已有 works.id，例如 ["blue-archive"]；不是 Bangumi 数字 ID                                                          |
| type               | 字符串 / 是     | 严格选择上表四个值，大小写保持同人Only                                                                                      |
| city               | 字符串 / 是     | 与现有城市命名一致，如上海，不混用上海市；地区选项会自动生成                                                                |
| district           | 字符串 / 是     | 所在行政区，如闵行区，不写场馆或商圈名                                                                                      |
| venue              | 字符串 / 是     | 场馆或店铺名称，如虹桥品汇、南十字星咖啡，不把完整地址放这里                                                                |
| floor              | 字符串 / 是     | 楼层或展厅，如4楼、A馆、歌剧厅；未确认填空字符串，不套用同商场其他活动的楼层                                                |
| address            | 字符串 / 是     | 包含城市、区、街道和门牌的地址，如上海市静安区曲阜路137号1层                                                                |
| coordinates.system | 字符串 / 是     | 只填 GCJ-02 或 WGS84，按坐标来源确定；高德和会员购 GD 为 GCJ-02                                                             |
| coordinates.lng    | 数字 / 是       | 经度，例如 121.473595，范围 -180 至 180，不能与纬度颠倒                                                                     |
| coordinates.lat    | 数字 / 是       | 纬度，例如 31.242359，范围 -90 至 90；核对实际场馆，不用城市中心代替                                                        |

coordinates 必须是包含 system、lng、lat 的对象。保留来源坐标，前端会转换，不提前重复转换。同址沿用已有的已核实坐标以便分组，不能把名称相似的场馆当同址。无法核实地址或坐标时先补证据，不用 0 作为占位。

### 日期、场次和状态

| 字段        | 类型 / 必填     | 怎么填与例子                                                                                                               |
| ----------- | --------------- | -------------------------------------------------------------------------------------------------------------------------- |
| startDate   | 日期字符串 / 是 | 活动第一天，如2026-10-03，不是开票日                                                                                       |
| endDate     | 日期字符串 / 是 | 活动最后一天，含当日；单日活动与 startDate 相同，不得更早                                                                  |
| hours       | 字符串 / 是     | 已核实的开放时间，如09:00–17:00；演出可写每天14:30、19:30。未知填空字符串                                                  |
| sessionNote | 字符串 / 否     | 必要的场次差异或时长，如约150分钟（含中场休息20分钟）；不要复制整段入场须知                                                |
| timezone    | 字符串 / 是     | 当前只支持 Asia/Shanghai；其他时区活动先提出功能建议，不使用错误时区录入                                                   |
| status      | 字符串 / 是     | 正常安排填 scheduled；主办方明确取消填 cancelled；延期且新安排未确定填 postponed。售罄不等于取消，日期已过也仍填 scheduled |

当前筛选将首尾日之间视为连续活动期，没有逐日闭馆或离散场次排期字段。已知有闭馆日或非连续演出时，应在 hours/sessionNote 写清并在 PR 说明筛选局限；不能把两天间隔很长的独立演出伪装成连续营业。延期后确认新日期时更新活动期，并恢复 scheduled，保留原 ID。

### 价格与入口

| 字段        | 类型 / 必填   | 怎么填与例子                                                                                                     |
| ----------- | ------------- | ---------------------------------------------------------------------------------------------------------------- |
| price       | 非负数字 / 是 | 来源公布的最低票价或预约价，单位人民币元，如88、69.9。免费才填0；不是可售库存报价，不用 unknown、负数或0代替未知 |
| priceMax    | 非负数字 / 否 | 多票档的最高价格，如428；不得低于 price，单一价格省略                                                            |
| priceUnit   | 字符串 / 否   | 默认按单人票理解；按桌预约填桌预约，其他单位按来源写清。不要把桌费写成每人费用                                   |
| reservation | 布尔值 / 否   | 付费预约而非买门票时填 true；普通售票可省略或 false。免费活动目前会自动显示预约入口                              |
| priceNote   | 字符串 / 是   | 未使用填空字符串；必要价格核验信息可保存，当前详情不显示此字段，不以它替代正确 priceUnit                         |

例：普通票88元、最高套票428元，填 price 为88、priceMax 为428；免费预约填 price 为0；30至366元的桌位预约填 price 为30、priceMax 为366、priceUnit 为桌预约、reservation 为true。保留能解释实际收费的单位，不新增免责声明。

### 图片、补充信息和来源

| 字段              | 类型 / 必填     | 怎么填与例子                                                                  |
| ----------------- | --------------- | ----------------------------------------------------------------------------- |
| poster            | URL字符串 / 是  | 已核实的官方或票务活动海报 HTTPS 直链，不填网页地址、二维码或场馆底图         |
| banner            | URL字符串 / 是  | 官方横图直链；没有横图时可复用 poster，不编造地址                             |
| posterAlt         | 字符串 / 否     | 简短图片描述，如蔚蓝档案同人ONLY勇者之路海报                                  |
| description       | 字符串 / 是     | 未使用填空字符串，或简短事实概述，不编造活动内容；当前详情不展示              |
| highlights        | 字符串数组 / 是 | 未使用填 []，不为凑字段生成卖点；当前详情不展示                               |
| notes             | 字符串数组 / 是 | 无补充填 []，用于保留来源冲突和核验事实，不在页面展示冗长须知                 |
| source.name       | 字符串 / 是     | 具体来源名，如哔哩哔哩会员购、大麦、猫眼演出                                  |
| source.url        | URL字符串 / 是  | 该活动的官方或票务详情页；也是当前购票/预约入口，不能填首页或与活动无关的页面 |
| source.verifiedAt | 日期字符串 / 是 | 实际完成本次核实的日期，只更新已核实条目，不用演出日或未来日期                |
| source.api        | URL字符串 / 否  | 实际用于核实的公开数据接口，没有则省略                                        |
| source.evidence   | 字符串 / 否     | 简短记录补充来源 URL、截图来源及冲突取舍，不声称截图是实时接口结果            |
| anniversary       | 正整数 / 否     | 兼容旧数据的纪念周年数，如30；不使用可省略                                    |
| heroLabel         | 字符串 / 否     | 兼容旧版展示的英文标识，新活动无需填写                                        |

source 必须是对象，至少包含 name、url、verifiedAt。图片以 // 开头时补 https:，使用外链，不添加本地图片文件。必填图片或价格无法确认时先补资料，不用无关内容凑齐字段。

## 核实与提交

- 优先活动官网、主办方公告和票务详情；去掉来源 URL 的跟踪参数及误带的标点，保留活动 ID。
- 会员购公开接口为 https://show.bilibili.com/api/ticket/project/getV2?id=项目ID 。检查返回成功，接口可能变化。price_low、price_high、票种价格以分计，除以100后入库；start_time、end_time 为秒级时间戳，按上海时区解释。
- screen_list 可能只含单日或当前可售场次，不据此缩短总活动期。分别核对活动期、每天开放时间、入场或点餐场次。
- 来源冲突时寻找更明确、更新的活动说明并记录取舍。关键事实无法确认时向用户补充核实，不猜测；草稿 PR 仅提交已核实的数据变更，待补项写 PR 正文，不新增文档或占位活动。
- 提交前逐项检查必填字段、合法 JSON、唯一 ID、作品关联、日期区间、坐标系、价格单位及来源。不要修改未核实活动的 verifiedAt。
- 无需安装环境或执行命令；PR 的 GitHub Actions 自动测试和构建。检查失败时只修正 src/data/events.json，不能修改校验规则、测试或其他文件。

具体分支或 Fork、PR 提交流程见 [SKILL.md](../SKILL.md)。
